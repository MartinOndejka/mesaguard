# Security policy

MesaGuard scans untrusted source trees as text. It does not execute the target project, install its dependencies, follow symbolic links, or send its contents over the network.

## Supported version

Only the latest release is supported during the initial preview.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting flow for this repository. Do not open a public issue containing an undisclosed vulnerability or sensitive project data.

Include the MesaGuard version, operating system, minimal reproduction, and potential impact. You should receive an acknowledgement within three business days.
