A narrow tool by design

Preflight is not proof.

MesaGuard does not compile a contract, generate or deploy keys, connect to a network, or certify circuit security. A clean static report means only that these known migration signals were not found.

Project-specific compilation, transaction testing, verification-key review, and deployment coordination still matter. The output makes those steps explicit instead of hiding them behind a green badge.
